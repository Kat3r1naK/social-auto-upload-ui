The platform logo PNGs in `public/assets/platforms/` were obtained from [DevilJie/QianFan-Sync](https://github.com/DevilJie/QianFan-Sync) at the revision above, fetched on 2026-11-13. The reference project's Apache-2.0 license and NOTICE are retained beside these files as `QianFan-Sync-LICENSE.txt` and `QianFan-Sync-NOTICE.txt`. Platform names and logos identify their respective services.

SAU Studio's mark, sample mountain photograph and creator avatar were generated for this interface with the built-in ImageGen tool. They are separate assets rather than source code copied from the reference project. The selected design reference is the first design generated in this chat.

- `sau-mark.png`: transparent violet folded play mark, used in the sidebar and favicon.
- `mountain-weekend.png`: misty green mountain landscape, used as fictional media content and preview imagery.
- `creator-avatar.png`: outdoor hiker photograph, used for fictional demo accounts.

Runtime dependency licenses remain those declared by their packages. In particular, the frontend uses Vue, Pinia, Vue Router, Element Plus, Axios, marked and DOMPurify, with Vite, TypeScript and vue-tsc for development and checking.
