# SAU Studio 前端重做

2026-11-13，用户选择本次设计探索中第一张深紫色工作台方案，并明确要求使用 TypeScript。

本文记录第一阶段界面工作。后续已接入 Electron、TS 本地业务及 SQLite，最新进展和验证范围见 [desktop-development.md](desktop-development.md)。以下“实际边界”描述界面阶段及目前仍保留的浏览器预览模式。

## 视觉与页面组织

- 统一深紫色视觉、文字层级、表单、弹窗、列表、空状态及焦点样式；另提供浅色主题。
- 左侧为工作台、发布中心、草稿箱、素材库、账号管理、任务中心和发布记录，设置和主题切换在底部。
- 发布中心使用“中间内容编辑 + 右侧目标账号和内容预览 + 底部固定操作”结构。
- 视频、图文、文章共用账号选择、公共配置与账号个性化覆盖方式；目标账号按内容类型过滤。
- 界面组织参考 QianFan-Sync 的公共配置、平台与账号分工，代码仍基于当前 fork；复制的平台标识资源保留第三方声明。

## 已实现的前端交互

- 示例与本机工作区分开保存草稿和任务，示例任务不会触发真实发布。
- 标题、正文、标签、文章 Markdown/HTML 预览及文件导入；预览 HTML 使用 DOMPurify 清理。
- 素材导入、搜索、分类、网格/列表视图、选择素材创建草稿。
- 示例账号新增、编辑、分组筛选；本机账号沿用现有四平台的登录、检查及管理接口。
- 草稿自动/手动保存、恢复、删除；发布目标选择、账号个性化内容；按账号生成独立队列项。
- 任务详情、取消尚未执行的任务、记录筛选、JSON 导出。
- 对本地服务不可用、未接入的平台及内容类型、无文件或无账号等情况给出明确反馈。
- 页面、入口、平台配置、接口和状态管理使用 TypeScript；严格类型检查纳入生产构建。

## 实际边界

本轮完成界面与本地交互。全部 17 个平台已进入能力配置和界面组织，但尚未完成新的全平台服务联调。现有四平台基础视频接口作为兼容入口保留；其不能表达的简介、图文/文章及新版定时任务会明确阻止提交，避免静默丢失内容。

当前草稿和任务保存在浏览器 localStorage。导入的本地媒体使用会话内 Blob URL，持久化只保存文件信息；刷新后需要重新选择媒体。示例内置素材、文章正文和上传至本机服务的媒体可以恢复。Windows 客户端后续需要将这些数据迁移到独立数据目录及 SQLite。

旧服务返回成功只记为“已提交、待核验”；执行中刷新或遇到结果不明确的错误时标记为“待核验”，不会自动重试。真实平台登录与实际发布本轮未执行。

TypeScript 检查与 Vite 生产构建已执行；浏览器验证证据及视觉对照见仓库根目录 `design-qa.md`。Electron 外壳、FastAPI 服务、SQLite 队列及 Windows 安装包按 `windows-client-plan.md` 继续实施。
