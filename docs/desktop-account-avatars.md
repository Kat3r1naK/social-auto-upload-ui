# 桌面账号头像

2026-11-14：设置页移除“原项目”和“界面参考”链接；保留仓库中的第三方声明。

登录或账号检查成功后，worker 尝试从当前账号的专属头像控件读取图片。图片归一为 128 × 128 PNG，缓存到工作区的 `avatars/`，通过 `sau-media://avatar/` 提供给界面。账号管理和发布中心共用头像组件；真实账号缺少头像或加载失败时显示别名首字，示例工作区继续使用示例头像。

头像获取超时、控件不唯一、图片未加载或缓存失败均不改变账号操作结果，并保留已有缓存。编辑账号、重启后保留头像；图片内容变化会更新缓存标识；解除本地绑定时清理缓存。

当前包含小红书、抖音、快手、视频号、Bilibili、知乎、YouTube、Instagram 的读取适配。只有小红书使用真实登录会话验证过，其余平台需要分别实测；未适配的平台跳过头像获取。读取只限账号控件，不使用信息流中的任意头像。
